# SpendDNA

AI-powered financial analytics SaaS for turning CSV/PDF bank statements into premium dashboards, reports, and natural-language insights.

## Stack
Next.js 15, React 19, TypeScript, Tailwind CSS, Recharts, Framer Motion-ready UI, Prisma/PostgreSQL, NextAuth-compatible schema, Zod, React Hook Form-ready forms, UploadThing-ready upload flow, PapaParse, pdf-parse, and Lucide icons.

## Commands
```bash
npm install
npm run dev
npm run typecheck
npm run build
```
